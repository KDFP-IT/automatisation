# Калькулятор траншеи

Откройте `dist/index.html` через локальный сервер: `npm start`, затем http://localhost:8765.

Страница без сборки и внешних JavaScript-зависимостей. Все расчёты выполняются локально, параметры сохраняются в localStorage браузера. Для полностью автономной работы достаточно удалить CSS-импорт шрифта: есть системный резервный шрифт.

`dist/model.js` — независимая расчётная модель; `dist/app.js` — форма, сохранение и SVG-схема; `dist/style.css` — адаптивное оформление и печать. Проверка модели: `npm test`.

Выемка: (b + B) × H × L / 2. Обратная засыпка: выемка минус полный наружный цилиндрический объём всех труб и объём привозной подсыпки. Подсыпка: (b × t + m × t²) × L. Избыток дан в плотном теле; коэффициенты разрыхления и уплотнения не применяются. Постоянное сечение, трубы в один ряд по всей длине, симметричные откосы. Длина в 3D схеме условная, поперечное сечение пропорционально. Это исходная модульная версия для последующего расширения.
