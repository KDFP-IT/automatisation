# Собрать КАЦ

Инструмент собирает полный блок прайс-листов в копии Word. Выберите основной DOCX, общую папку прайс-листов с папками `Раздел N - Название` и новую папку для результата. Если выбрать папку одного раздела, инструмент обновит только его существующий блок в Word.

## Входные данные

- **Сводная таблица (необязательно)** — XLSX. После заголовка сводной таблицы в DOCX должен находиться пустой абзац с разрывом раздела. Обработчик LibreOffice Calc в Linux вставляет таблицу альбомными страницами A3.

- **Основной документ** — DOCX проекта. В нём нужны оформленные разделители `ПРАЙС-ЛИСТЫ К РАЗДЕЛУ КАЦ №N` с блоком изображений КП либо пустым абзацем; для разделов без разделителя он создаётся по образцу первого. При полной сборке пустые и заполненные блоки нельзя смешивать. Если DOCX лежит в корне выбранной папки проекта, интерфейс находит его сам; серверный шаблон задаётся через `KAC_TEMPLATE_DOCX`.
- **Коммерческие предложения** — папки `Раздел N - Название`, внутри PDF с именем `КП N.M …`:
  - PDF читаются только с первого уровня папки раздела, подпапки (`арх`, `Картинки`) игнорируются;
  - номера КП в разделе не повторяются, один раздел не может лежать в двух папках;
  - разделы без PDF пропускаются и перечисляются в отчёте.
- Порядок КП в PDF — по номеру (`КП 1.1`, `КП 1.2`, `КП 2.1`, …), страницы каждого КП — в исходном порядке файла.

## Результат

- `КАЦ — полный комплект.pdf` (в режиме одного раздела — `КАЦ — раздел N.pdf`): документ Word со вставленными страницами КП, обновлённым оглавлением и нумерацией.
- При загрузке сводной таблицы доступен подготовленный XLSX. DOCX и изображения используются как промежуточные файлы.

## Отдельный запуск в Docker

Выполните из корня репозитория:

```sh
docker build -t kdfp-portal-kac:local -f apps/kac/Dockerfile .
docker run --rm -p 127.0.0.1:8080:8080 kdfp-portal-kac:local
```

Откройте [«Собрать КАЦ»](http://127.0.0.1:8080/kac/). Загрузите DOCX, при необходимости XLSX, и папки КП. PDF экспортируется через LibreOffice. Если нужен серверный шаблон, смонтируйте DOCX в контейнер и укажите его путь в `KAC_TEMPLATE_DOCX`. Для точного воспроизведения Times New Roman в PDF установите этот шрифт в окружении экспорта.

## Интерфейс

Экран `/kac/` собирается из `apps/kac/ui` (Vue 3 + Nuxt UI) в `apps/kac/static/ui`; в git результат не попадает. Сборку выполняет Dockerfile, локально:

```sh
cd apps/kac/ui
npm ci
npm run build
```

Для правок интерфейса запустите Flask (`python serve.py --port 8099` из этого каталога) и Vite (`npm run dev` из `apps/kac/ui`), затем откройте http://127.0.0.1:5174/kac/ui/ — Vite проксирует `/kac/api` на Flask. Node.js нужен только на машине разработчика и при сборке образа.

## Запуск в Windows

Нужны Windows, настольный Microsoft Word и Python 3.10 или новее. Установите зависимости из каталога инструмента:

```powershell
py -3 -m pip install -r requirements.txt
```

Откройте `Sobrat-KAC.cmd` и введите пути или передайте их при запуске:

```powershell
.\Sobrat-KAC.cmd "D:\Проект\Основной.docx" "D:\Проект\Прайс-листы" -o "D:\Проект\Сборка КАЦ"
```

Перед сборкой программа покажет порядок КП и общее число страниц. Вариант для пакетного запуска принимает `--yes`.

- Берутся PDF непосредственно из папок разделов. Имя каждого файла должно начинаться с номера вида `КП 1.2`. Разделы и две части номера КП сортируются как числа, страницы каждого КП идут в исходном порядке. Пустые папки выводятся в отчёте запуска.
- В конце Word нужен хотя бы один оформленный разделитель вида «ПРАЙС-ЛИСТЫ К РАЗДЕЛУ КАЦ №1» и следующий за ним абзац со встроенными изображениями либо пустой абзац. При полной сборке все существующие блоки должны быть одного типа. Недостающие разделители создаются по этому образцу. Для существующего блока Word должна быть папка с исходными КП.
- Если первый разделитель и предыдущий раздел Word начинают нумерацию с одного номера, первый разделитель продолжает нумерацию предыдущего раздела. При полной сборке дальше нумерация идёт подряд через все разделители и листы КП. Word обновляет оглавление и проверяется размещение каждой страницы КП на отдельном листе.
- Сборка сохраняет новый DOCX, PDF, JPEG каждой страницы и `Страницы КП.csv` с физическими номерами страниц PDF и номерами, рассчитанными Word. Исходный DOCX и PDF предложений остаются на своих местах.
