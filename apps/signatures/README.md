# КДФП — проверка всех фамилий в ПД

Готовые пакеты для сервера и инструкция: [DEPLOY.md](DEPLOY.md).
Все зависимости браузера, включая SHA для внутренних HTTP-адресов,
поставляются локально. Лицензии — в `dist/vendor`.

Локальная страница: запустите `start.cmd`, откроется http://127.0.0.1:8774/.
Нужен Python 3; зависимости для запуска не требуются. Папку `dist` также можно
разместить на любом внутреннем статическом HTTP-сервере.

Выберите один PDF. SIG необязателен: без него страница собирает список фамилий для подписания. Для сверки добавьте все файлы SIG/SGN/P7S этого PDF.
По умолчанию анализируется весь PDF (до 1000 страниц), включая чертежи.
Можно задать начальную страницу и число страниц (до 200 за один диапазон).
Чертежи за пределами выбранного диапазона в этом случае не проверяются.

В список включаются все распознанные фамилии, а не только ГИП и директор.
Показаны страницы, инициалы и найденные соответствия. Повторы объединяются.
Фамилии без инициалов определяются с помощью локального словаря OpenCorpora;
редкие фамилии и нестандартные таблицы могут потребовать правки списка.
Морфологические неоднозначности и названия улиц полностью автоматически
разрешить нельзя — проверьте список по PDF перед использованием отчёта.
Для сканов без текстового слоя требуется предварительное OCR.

## Чертежи и рукописные подписи

Правило учёта разделено по типу страницы:

- В текстовой части учитывается только совпадение с подписантом SIG.
  Оно засчитывается во всех найденных текстовых местах этого человека.
- На чертежах учитывается только рукописная подпись в конкретной строке.
  Наличие человека в SIG не закрывает графы подписи на чертежах.
- Рукописная отметка вне чертежа не заменяет SIG для текстовой части.
- Если выполнена только часть требований, результат «Частично».

Страницы со стандартными штампами определяются как чертежи; это правило
применяется также к другим упоминаниям фамилий на такой странице.
CSV отдельно показывает текстовые страницы, где засчитан SIG,
и чертежи с найденной, отсутствующей или требующей проверки рукописной.

Текст обрабатывается в координатах видимого листа с учётом поворота PDF.
Близкие фрагменты слова объединяются. Для стандартного штампа 185×55 мм
читается вся строка: должность, соседние фрагменты фамилии и графа подписи.
Для выявленного CAD-шрифта восстанавливается кириллица смешанных слов:
например, `ТруǪников` читается как `Трубников`; исходный текстовый слой
сохраняется в источнике для проверки. Это восстановление кодировки, не OCR.
Поддержаны короткие переносы фамилии внутри ячейки. Короткие неразрешённые
обрывки помечаются для уточнения, а не угадываются по словарю.
Другие размеры и нестандартные штампы могут требовать ручной проверки.

Изображение граф подписи анализируется в масштабе 3:1, длинные линии таблицы
отбрасываются. Выраженные росчерки учитываются как подпись по изображению;
разреженные и неоднозначные штрихи получают статус «проверить росчерк».
Это простая визуальная эвристика, а не нейросетевой OCR и не проверка
подлинности рукописной подписи. Пустые или непрочитанные графы можно
перепроверить вручную. Автоматический анализ не исключает пропусков.
На растеризацию граф одного листа отводится до пяти секунд; при превышении
времени графы остаются непроверенными. Такой результат требует просмотра,
а не выдаётся за отсутствие подписи.

Откройте страницу по ссылке у фамилии: оранжевым выделена строка ФИО,
синим — соседняя графа подписи. Для чертежей штамп открывается крупно,
с переключением на весь лист. Выберите «Есть рукописная подпись» или
«Рукописной подписи нет» для конкретной строки. Автоматически найденный
росчерк или ручное подтверждение учитываются в результате и CSV без SIG.
Автоматическая отметка является эвристикой наличия чернильных штрихов,
может ошибаться и не подтверждает автора или подлинность подписи.
Если подтверждена только часть найденных мест человека, результат
«Частично», а не «всё подписано». Для каждой строки штампа ведётся отдельная
отметка; подпись на одном листе не закрывает остальные места документа.
При повторной проверке того же PDF в текущей вкладке ручные отметки
сохраняются по строкам. Тождество файла проверяется по SHA-256; на другой
PDF подтверждения не переносятся. После обновления страницы отметки теряются.

Файлы читаются в браузере, не загружаются на сервер и не сохраняются между
сеансами. Все шрифты, PDF.js и словарь поставляются локально.
Интерфейс состоит из загрузки файлов и списка подписантов. Параметры обработки свёрнуты. Примеры и рекламные блоки удалены. Основной текст — 16 px, фамилии — 18 px, заголовки разделов — 22 px. Доступны фильтры результатов, редактирование списка в отдельном окне, просмотр PDF и CSV.
В каждой строке есть ссылки на все страницы-источники и кнопка «Исправить».
Ссылка открывает выбранную страницу, выделяет строку распознавания и показывает
исходный текст. Здесь же можно изменить фамилию/должность или убрать запись.
После исправления исходные страницы и текст сохраняются. В просмотре можно
перейти к любой странице PDF, включая страницы после двадцатой.
Встроенные подписи PDF и присоединённые контейнеры не учитываются: поддержаны
отсоединённые CMS/PKCS#7 в бинарном DER, PEM и Base64.

## Что проверяется

Читаются именно SignerInfo и связанные с ними сертификаты по issuer/serial
или SubjectKeyIdentifier. Наличие сертификата в цепочке само по себе не
считается подписью. Сопоставляются фамилии и все указанные имя/инициалы;
при нескольких людях с одинаковыми инициалами результат «Уточнить».

Это сверка записей и имён, а не полноценная криптографическая проверка ЭП.
Для SHA проверяется signed attribute messageDigest относительно PDF;
несовпадающие записи исключаются. Для ГОСТ хеш, связь с PDF, подлинность
подписи, цепочка доверия, отзыв и временные метки не проверяются.
Для подтверждения этих свойств используйте КриптоПро или КриптоАРМ.
Ошибка чтения SIG переводит потенциально отсутствующие подписи в «Уточнить»,
чтобы не выдавать неполный разбор за отсутствие подписи.

## Проверки

`node --test tests/*.test.mjs`

Для интеграционного теста задайте `KDFP_TEST_SIG` путём к предоставленному SIG.
Рабочие копии распознанного текста исключены из исходников через `.gitignore`.
Словарь можно пересобрать `build_names.py`, установив `pymorphy3` в `.names-deps`.
Лицензии библиотек и данных находятся в `dist/vendor`, фирменных материалов —
в `dist/assets/SOURCES.md`. Палитра, логотип и шрифты основаны на kdfp.ru.
