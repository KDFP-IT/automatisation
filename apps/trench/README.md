# КДФП · Трасса и земляные работы v7.3.0

Параметрическая модель сети: общий план → участок между колодцами → труба или колодец. План, профиль, объёмный вид и сечения используют общие данные. Расчёт выемки и обратной засыпки с грунтовыми слоями, футлярами, откосами, подготовкой и отдельными котлованами.

Связанные виды участка открываются при его выборе: щелчок по плану или профилю, ползунок и расстояние в метрах задают общую точку сечения. Кнопка «Таблица участков» ведёт к ведомости с выемкой, засыпкой, грунтами и отдельными итогами траншей и котлованов. Нажатие на строку открывает участок.

Подробная инструкция, принципы расчёта и ограничения: [NETWORK.md](NETWORK.md).

## Запуск

Нужны Docker Engine и Docker Compose:

```sh
docker compose up -d --build
docker compose ps
```

Адрес: http://localhost:8086 или `http://IP-СЕРВЕРА:8086/`. Изменение порта: файл `.env` с `PORT=8090`.

Для сборки требуется Docker Hub. Для сервера без доступа к реестру используйте готовый offline-комплект v4.3: в нём образ, контрольная сумма, Compose без сборки и инструкция установки. Не используйте `--build` для offline-комплекта.

После запуска интернет не нужен. Nginx работает без root. Проверка готовности — `/healthz`. Старый одиночный калькулятор доступен по ссылке «Быстрый расчёт» (`quick.html`).

## Проект и ограничения

При запуске открывается список проектов из серверной БД. Внутри проекта находятся самостоятельные схемы. Прежние модели можно скопировать кнопкой «Перенести локальные модели». Пилот Д12 / Д12′ — КК2-12 переносится как отдельная схема. Схема связей, длины и часть отметок взяты из профиля проекта; координаты, конструкции и геологию нужно подтвердить. Это настраиваемый пилот, а не готовый расчёт проекта «Кулько».

Можно создать пустой проект, добавлять узлы и участки, редактировать входы/выходы, горловины и рабочие части, задавать повороты, уклоны, футляры, расчётные отрезки, левый/правый откос и слои грунта. Проекты и схемы хранятся в общей SQLite через API (Flask/Gunicorn), файл /data/trench.sqlite3 в постоянном Docker-томе trench-data. Изменения схемы автоматически сохраняются. Проверка версии защищает от перезаписи изменений другого инженера; при конфликте можно открыть серверную версию или сохранить свою копию. Учётных записей и разграничения прав нет. JSON остаётся способом обмена и экспорта.

Расчёт траншей численный. Котлованы исключаются из траншей; общие узлы не дублируются. Пересечения котлованов и осей траншей вне котлованов блокируют общий итог. Полное объединение произвольных контуров траншей, автоматическое определение всех параллельных перекрытий и CAD-импорт не реализованы. Все объёмы в плотном теле, без разрыхления и уплотнения. Подробные ограничения — в NETWORK.md.

## Проверка и разработка

```sh
node --test
pip install -r api/requirements.txt
python -m unittest tests_backend -v
```

`network-model.js` — модель и расчёт; `network-views.js` — SVG; `network-linked.js` — выбор общей точки и ведомость участков; `network-app.js` — редактор; `network.css` — интерфейс. Предыдущий калькулятор: `model.js`, `app.js`, `quick.html`. Node.js нужен только для тестов, в рабочем контейнере он не требуется.

Шрифт Montserrat, логотип и стили включены в образ. Лицензия шрифта находится в `dist/assets/Montserrat-OFL.txt`.

Версия 3.3: читаемые поля и подписи, компактная рабочая область, редактор грунтов с переносом и отменой, отдельная вкладка основания с материалом подушки и объёмами. Подробности — NETWORK.md.

Версия 4.0 — конструктор: «Выбрать / Колодец / Соединить», одна рабочая сцена, карточка объекта и отдельная ведомость. Общая отмена и предпросмотр геометрии. Старые проекты автоматически копируются в отдельное хранилище; прежние записи не перезаписываются. Подробности и откат — NETWORK.md.

Версия 4.1: меню проектов → схемы → конструктор; создание, переименование, копирование; SQLite и резервная копия через api/backup.py. Запускайте приложение через Docker Compose, чтобы были доступны и страница, и API. Статический HTTP-сервер не обеспечивает хранение проектов. Подробнее: DEPLOY.md.

Версия 4.2 — проверка связанных объектов: занятые подключения, габариты и высоты входов, взаимное положение труб/футляров/рабочих частей, перекрытия траншей вне котлованов и покрытие грунтами каждой зоны. Замечания разделены на ошибки и предупреждения, ведут к объектам и подсвечивают связанные поля. Ошибки блокируют расчёт объекта/общий итог, геометрически некорректная схема может сохраняться черновиком. Переключение способа задания откосов сохраняет геометрию. Нормативные минимумы и гидравлика не подставляются автоматически.

Версия 4.3: углы наклона в профиле, сечении и 3D. β — продольный угол трубы в выбранной точке, i — уклон в промилле; плюс означает падение от начала к концу, минус — подъём. αл/αп — углы откосов от горизонтали. Числа вычисляются по реальным параметрам и не зависят от масштаба рисунка или камеры. Параметры и расчёт объёмов не меняются.

Версия 4.5.0: архив проектов/схем, корзина, восстановление и окончательное удаление с вводом названия. Управление доступно в карточке через «Ещё» и вкладки «Активные / Архив / Корзина». БД обновляется автоматически до схемы 2, перед обновлением сделайте резервную копию. Объекты в архиве/корзине и схемы таких проектов недоступны для изменения, старые вкладки не могут затереть данные. Ранее удалённые отдельные схемы не восстанавливаются вместе с проектом автоматически.
