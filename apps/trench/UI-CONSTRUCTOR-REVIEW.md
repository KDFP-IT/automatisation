# КДФП: разбор интерфейса как инженерного конструктора

3 ноября 2026 · текущая версия 3.3

## Вывод

Нужна одна рабочая сцена: **поставить колодцы → соединить → настроить участок → получить выемку и засыпку**. Сейчас выбор объекта одновременно меняет представление, режим и открытость панели. Поэтому уменьшения подписей недостаточно: следует разделить **выбранный объект, инструмент и вид**.

Разбор выполнен по исходникам, документации NETWORK.md и существующим представлениям интерфейса. Это экспертная оценка, не пользовательское исследование. Код и пользовательские проекты не менялись. Ниже отдельно обозначены обнаруженное поведение и предложения UX.

## Что сохранить

Общие колодцы и подключения, связанные план/профиль/сечение, выбор расстояния вдоль трассы, отдельный учёт котлованов, баланс материалов и грунтов. Сохранить читаемые поля v3.3, редактор слоёв с переносом/отменой и отдельное основание. Расчётную модель ради новой композиции переписывать не нужно.

## Оценка главных параметров UI

| Параметр | Сейчас | Предлагаемый конструктор |
|---|---|---|
| Первое действие | Демонстрационная сеть либо `+ Узел`; объект ставится в автоматически выбранную точку. | Пустой план и одна команда «Поставить первый колодец». |
| Сборка связей | Диалог с начальным/конечным узлом и двумя подключениями. | Соединить щелчком два колодца; выбор подключения только при неоднозначности. |
| Навигация | Масштабы, список, крошки, подключения, виды, переходы из ведомости. | Один выбор на сцене/в списке, отдельный переключатель видов. |
| Параметры | Одновременно раскрываются несколько групп конструкции и трассы. | Основные поля; «Дополнительно» для остальных. Активные нестандартные настройки видны кратким резюме. |
| Грунты/основание | Полезные редакторы, но повторяющиеся кнопки входа и не всегда очевидная зона действия. | По одному постоянному входу; явная подпись «Зона 2: 0,50–27,56 м» и отдельно «Материалы всего участка». |
| Результаты | Хорошее положение над схемой; область меняется с масштабом/выбором. | Постоянный переключатель «Выбранный участок / Весь проект» и статус данных. |
| Композиция | Связанный режим занимает четыре блока; открытие инспектора меняет размеры схем. | Одна большая схема; сравнение видов по запросу. Фиксированное место инспектора. |
| Типографика | Поля v3.3 уже читаемы; вертикальную площадь расходуют повторные панели. | Не увеличивать всё дальше: значения около 16 px, подписи 13–14 px, результаты 24–28 px; сократить число постоянных блоков. |
| Ошибки | Общий текст под рабочей областью, краткие индикаторы объектов. | Ошибка у поля, индикатор у объекта, переход к проблеме; без длинных инструкций. |

Это предложения UX, а не установленные инженерные нормы. Основной выигрыш даст уменьшение конкурирующих режимов и переходов, а не новая палитра.

## Семь действий первого уровня

Три инструмента конструктора + три группы инспектора + ведомость. Это семь функций с устойчивым местом, а не семь больших кнопок в одной строке.

1. **Выбрать** — выбор и перемещение выбранного объекта; Escape возвращает инструмент выбора.
2. **+ Колодец** — поставить на плане, автоматически предложить обозначение, открыть карточку.
3. **Соединить** — указать два колодца, увидеть предпросмотр связи.
4. **Труба и траншея** — параметры выбранного участка.
5. **Грунты** — материалы, порядок и толщины.
6. **Основание** — подушка, обсыпка, защитный слой.
7. **Ведомость** — таблица с итогами и возвратом к выбранному участку.

**Проект ▾** содержит создание, открытие, сохранение, исходные документы, примеры и печать. Отмена/повтор доступны всегда. **План / Профиль / Сечение / 3D** остаются компактным переключателем изображения, не создают дополнительных уровней модели. При постановке и соединении активен план; уход из плана явно завершает инструмент.

## Схема экрана

```text
КДФП  Проект ▾  Название                         ↶ ↷  Ведомость
Выемка …  Засыпка …    [Выбранный участок ▾]   Предварительно • 3
──────────────────────────────────────────────────────────────
Участки          Выбрать | + Колодец | Соединить   Карточка
Д13 → Д13′       План / Профиль / Сечение / 3D     Д13 → Д13′
  28,06 м                                         Труба и траншея
Д13′ → КК2-13    ОДНА БОЛЬШАЯ СХЕМА               Грунты | Основание
[Колодцы ▸]      + выделение объекта              Основные поля
                 + выбранная точка                Дополнительно ▸
──────────────────────────────────────────────────────────────
Точка 14,03 / 28,06 м  Земля …  Низ трубы …  Глубина …
```

Список участков — основной навигатор. Колодцы остаются на плане и в сворачиваемой группе для сложных сетей. Отдельную навигацию «Общая трасса / Участок / Объект» убрать. Ведомость заменяет рабочее представление, а не располагается ниже нескольких экранов форм; возврат сохраняет вид, выбор и расстояние сечения.

## Сущности и минимальные поля

| Сущность конструктора | Текущая модель | Первый уровень | Дополнительно |
|---|---|---|---|
| Колодец/камера | `wells[]` | Обозначение, поверхность, форма/внутренний размер, конструкция из шаблона либо пользовательская, внутреннее дно. | Стенки/плиты, рабочая часть, горловина, котлован, подготовка, точные X/Y. Краткое резюме этих размеров и условность шаблона всегда видны. |
| Вход/выход | `well.ports[]` | Создаётся при соединении; выбор из существующих нужен при неоднозначности. | Несколько подключений с собственными отметками. |
| Участок трубы | `edges[]` | Семь значений: длина по плану (читаемая), диаметр, начало низа трубы, конец **либо** уклон в выбранном режиме, ширина дна, откос, выбранная зона с границами. | Стенка, футляр, разные откосы, прокладка без траншеи, повороты, фиксированные отметки. |
| Поворот/точка профиля | `waypoints[]` | Вершина на линии, выделяемая на схеме. | Координаты и фиксированные отметки. |
| Зона участка | `sections[]` | Полоска интервалов с расстояниями, выделение и разделение в выбранной точке. | Привязка границ по расстоянию либо доле длины. |
| Грунтовая толща | `layers[]` участка/колодца | Материал и толщина, перенос/стрелки; нижние границы вычисляются. | Глубины, разные толщины на концах, группа, цвет. |
| Основание | Поля выбранной зоны | Есть/нет подушки, материал, толщина, обсыпка и защита. | Подробный материальный баланс и узел. |

Для грунтов переключатель «Одинаково по участку» уменьшает число полей. Если исходные границы различаются, автоматически показывать обе колонки, сохраняя градиент. Не изображать независимые грунты колодцев и участков как автоматически согласованную общую геологию.

Для трубы и стенки удобен ввод в мм с переводом во внутренние метры; отметки и траншея — в метрах, уклон — в ‰. Симметричные откосы можно связать кнопкой, оставив независимые значения по явному выбору. Группа грунта не должна автоматически назначать «правильный» откос. Материал подушки не назначает плотность, уплотнение или несущую способность.

Траншея не требует отдельного объекта, вручную прикрепляемого к трубе: существующие зоны уже содержат её геометрию. Это сохраняет понятную сборку и нынешнюю структуру расчёта.

## Типовой сценарий

1. Создать пустой проект, поставить К1 и К2, указать поверхность и конструкцию.
2. Соединить их. На плане видна направленная связь, справа — «К1 → К2».
3. Задать трубу и траншею; открыть профиль и увидеть следствие ввода.
4. Задать грунты; сечение соответствует общей выбранной точке.
5. Задать подушку и защиту; меняются изображение и баланс материалов.
6. Увидеть область результата и статус данных; открыть ведомость либо продолжить трассу от К2.

Это этапы работы, а не обещание определённого числа щелчков. Общий колодец при продолжении трассы не дублируется.

## Безопасность преобразований и доверие к данным

**Длина и направление.** Обычное поле длины сделать читаемым. Команда «Задать длину» показывает фиксированный конец, предпросмотр и короткую строку: «К2 переместится; затронуты ещё 2 участка». Применение и отмена восстанавливают все связанные координаты, отметки и зоны одной операцией. Пропорциональное масштабирование зон — явный режим. При фиксированных расстояниях сокращение трассы не должно молча обрезать футляр.

**Уклон.** Режимы «По отметкам» и «По уклону» явно определяют зависимую величину. Фиксированные точки профиля не стираются молча. Ввод даёт предпросмотр, Enter/выход из поля — одну команду, Escape возвращает прежнее значение. Перетаскивание целиком — одна команда истории.

**Статус исходных данных — отдельно от `result.valid`:**

- **Черновик:** данные отсутствуют или противоречивы; следующая необходимая правка и поле видны.
- **Предварительно:** расчёт выполним, но есть заготовки, неизвестная геология или непроверенный смысл отметок. Числа постоянно обозначены как предварительные.
- **Исходные данные подтверждены:** инженер подтвердил параметры и источники. Это не нормативная экспертиза и не отмена ограничений модели.

Происхождение поля: «из чертежа / введено / шаблон / не задано». Подтверждённая длина «Кулько» не подтверждает автоматически грунты и конструкцию колодцев. Отсутствующую геологию нельзя заменять группой II и глубиной 20 м ради готового итога. Поля, скрытые в «Дополнительно», всё равно участвуют в расчёте и требуют ясного статуса.

## Приоритет реализации

1. **Предсказуемость и структура:** исправить контекст фабрик; маркировать условные данные; разделить выбор/вид/инструмент; убрать дубли и меню масштабов. Сохранить ID и расчётный движок.
2. **Минимальный конструктор:** постановка на плане, соединение с предпросмотром, контекстный выбор и общая отмена/повтор. Модальный выбор подключений — только при неоднозначности.
3. **Параметры и зоны:** основной/дополнительный уровень, явные режимы отметок/уклона, безопасные преобразования длины, полоска зон. Существующие грунты и основание встроить в эту структуру.
4. **Проверка с инженерами:** задача «два колодца, труба, трапеция, два грунта, подушка» без объяснения устройства программы. Исправить места, где потребовалась помощь, до CAD-импорта и новых каталогов.

## Критерии готовности

- Инженер собирает базовую сеть и в любой момент понимает выбранный объект, активный инструмент и область показанных объёмов.
- Выбор сохраняет вид; смена вида сохраняет объект и точку сечения.
- Изменение общей геометрии показывает затронутые связи; отмена восстанавливает модель и результаты целиком.
- Ввод уклона не уничтожает фиксированные точки без явного решения.
- Перестановка грунта сохраняет толщину; режимы толщин и глубин различимы; отмена слоёв входит в общую историю.
- Нулевая подушка даёт нулевой её объём; футляр определяет внешнюю опорную оболочку без двойного вытеснения трубы.
- Новый объект в проекте с любым каталогом грунтов не получает отсутствующие ID.
- Условная модель остаётся предварительной при математически корректном результате.
- Ошибка ведёт к полю; ведомость и JSON сохраняют выбор/геометрию/связи и статусы исходных данных в предусмотренном для них объёме.

Основной результат следующего этапа — короткий и надёжный сценарий сборки, а не ещё один слой оформления.
